# Elementle 

I like games like Flagle, Worldle, Travle and I just discovered Elementle, however you need to pay to play the unlimited version, so I decided to just recreate it, from scratch. In the process I also had the idea to have a different version, that is available in the Element recall tab, in which you have already available all the informations about the element, excluding the Symbol and the name, your goal is just to find those, either by remembering, or with the help of the wordle like charachter exclusion/highlighting.
